# Preferences - Team Lead View

Customize your coaching portal experience with personalized settings, notification preferences, and dashboard configurations to optimize your team management workflow.

## Overview

The Preferences section allows you to tailor the portal to your specific needs as a team lead, ensuring you receive the right information at the right time while maintaining an efficient workspace.

## Dashboard Preferences

### Default Dashboard View

- Set your preferred landing page when logging in
- Choose default time ranges for metrics display
- Configure which teams to show by default
- Select preferred chart types and layouts

### Widget Configuration

- Choose which performance metrics to display prominently
- Customize the order and size of dashboard widgets
- Set up alerts for key performance indicators
- Configure team comparison views

## Notification Settings

### Course Management Notifications

- New course enrollment alerts
- Course completion notifications
- Assignment deadline reminders
- Quiz result summaries

### Team Performance Alerts

- Performance threshold notifications
- Goal achievement celebrations
- Coaching session reminders
- Team milestone updates

### System Notifications

- Platform updates and new features
- Scheduled maintenance alerts
- Security notifications
- Policy changes

## Display Settings

### Interface Customization

- Choose light or dark theme
- Select preferred color scheme
- Adjust font size and display density
- Configure sidebar and navigation preferences

### Data Visualization

- Set default chart types for analytics
- Choose metric display formats
- Configure trend analysis periods
- Customize report layouts

## Communication Preferences

### Email Settings

- Weekly team performance summaries
- Monthly coaching reports
- Urgent alert notifications
- Course assignment confirmations

### In-App Notifications

- Real-time performance alerts
- Course completion updates
- Team achievement notifications
- System announcements

## Privacy Settings

### Data Sharing

- Control team data visibility
- Manage coach access permissions
- Configure external reporting
- Set anonymization preferences

### Activity Tracking

- Customize usage analytics
- Control performance tracking
- Manage session recording
- Set data retention preferences

---

> **Optimize Your Experience**: Regular review of your preferences ensures the portal continues to meet your evolving needs as a team lead. Contact support if you need assistance with any settings.
