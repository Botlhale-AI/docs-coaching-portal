A course is training you build once and Vela assigns automatically. You set the score range that triggers it, and on each evaluation cycle every agent whose scores fall in that range receives it. Courses reach people by score rather than by name, so you set the criteria rather than picking individuals.

---

## Before You Begin

You need:

- **A gap worth training.** Build the course around a category several agents are behind in. See [Read the Coaching Dashboard](./Dashboard.md).
- **Your material ready.** A file to upload, a link to point at, or both.
- **To know your evaluation cycle.** Assignment happens on the cycle set under Preferences, so a course created today reaches agents at the next run rather than immediately. See [Set Coaching Preferences](./Preferences.md).

---

## 1. Open the Courses Page

Select **Coaching** in the left sidebar, then **Courses**. The page lists what already exists, so check whether a course covering this gap is already there before building another.

![The Courses list, showing the courses that already exist](../img/screenshots/team_lead/courses/courses-list.png)

Select **Create Course** to start a new one.

---

## 2. Describe the Course

On **Create a New Course**, fill in the details:

| Field | What it does |
| :--- | :--- |
| **Course Title** | The name agents see in their list |
| **Description** | What the course covers, and why it was assigned |
| **Category** | Groups related courses. Select **Enter category name** to add a new one |

![The Create Course form, with the course title, description, and category fields](../img/screenshots/team_lead/courses/create-course.png)

![The course details step of the create form](../img/screenshots/team_lead/courses/create-course-course-details.png)

Write the description for the agent receiving it. "Improve compliance" says less than "Covers the disclosures required at the start of a call, and when each applies."

---

## 3. Add the Material

**Course Content** holds what the agent works through. There are two kinds, and a course may use both:

- **Course Material**: drag and drop a file, or select the area to browse. Files are limited to 10MB.
- **Course Link**: an **External Link** that opens elsewhere.

You can also choose a cover image for the course.

![Choosing a theme image for the course](../img/screenshots/team_lead/courses/create-course-choose-theme.png)

---

## 4. Add a Quiz

Select **Add Question** for each question you want to ask. Each question takes its options and a **Correct Answer**. For questions that need writing rather than picking, use a **Long Paragraph** answer.

![Adding quiz questions to a course](../img/screenshots/team_lead/courses/create-course-add-quiz.png)

The pass mark is set once for all courses under Preferences, not per course. See [Set Coaching Preferences](./Preferences.md).

---

## 5. Set the Deadline and Scope

**Deadline** is the number of **Days** an agent has from the date the course is assigned to them, rather than a fixed calendar date. Each agent's **Due Date** is worked out from the day they receive it.

Set the scope to **Entire Organisation** or to specific **Departments**, so the course only reaches the people it applies to.

![Setting the deadline on a course](../img/screenshots/team_lead/courses/create-course-deadlines.png)

Select **Create** to save. The course is assigned on the next evaluation cycle.

---

## 6. Edit a Course

Open a course from the list and select **Edit Course** to change its details, material, or questions.

![Editing an existing course](../img/screenshots/team_lead/courses/team-lead-courses-edit.png)

Editing changes the course for agents who have not yet completed it. Agents who already finished keep the result they earned.

---

## Check Your Work

The course appears in the list as soon as you save it. That confirms it exists, not that anyone has it.

To confirm assignment, open **Progress** after the next evaluation cycle and look for agents against this course. Nothing there before the cycle runs is expected rather than a fault. See [Track Learning Progress](./Progress.md).
